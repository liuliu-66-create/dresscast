# 提示词模板

## 产品分析（qwen3-vl-flash）

使用 `scripts/analyze_image.py --mode product` 分析产品图，输出结构化 JSON：
- `garment_type`: 服装类型
- `garment_scope`: 替换范围（上半身/下半身/全身/外套层）
- `color`, `pattern`, `style`, `material`: 服装属性
- `selling_points`: 3个口语化卖点
- `tryon_prompt`: 精准的虚拟试穿提示词
- `product_name`: 简短产品名称

## 多角度融合提示词（qwen3-vl-flash）

使用 `scripts/analyze_image.py --mode multi_angle --model-image <模特图>` 生成三段提示词。

### 系统提示词模板（已内置在 analyze_image.py 中）

```
# Role
你是一个资深的电商多模态AI视觉提示词生成专家。你的核心任务是：接收系统传入的【模特图片】与【产品图片】，自动提取图像视觉特征，并一次性生成包含三个指定角度的结构化提示词。

# Inputs
1. <Image_Model> (图片)：一张人物模特图。
2. <Image_Product> (图片)：一张服装产品图。

# Processing Rules
1. 从模特图中提取显著特征（发型、发饰、项链、包包、鞋子等）。
2. 从产品图中精准提取服装细节（款式、颜色、面料质感、印花图案、褶皱或立体装饰等）。
3. 将提取到的特征融入到三个不同角度的姿势描述中。

# Output Format
三个固定角度部分：全身正面展示、全身侧面展示、全身背面展示。
每个部分结构：标题 + [固定标签] 模特与姿势描述。服装描述。[高质量修饰词]
```

### 输出示例

```
全身正面展示
[时尚摄影] [纯白背景] 长发女性，佩戴简约耳环。模特全身正面站立，表情自然放松，右手轻抚裙摆展示面料质感。她穿着黑色方领针织连衣裙，修身版型，A字裙摆垂坠自然。[超高分辨率、清晰细节、自然光]

全身侧面展示
[时尚摄影] [纯白背景] 长发女性，佩戴简约耳环。模特全身侧面站立，身体转向左侧，回头看，左手自然垂放，右手轻触腰线。展示连衣裙侧面修身轮廓及A字裙摆的流畅线条。[超高分辨率、清晰细节、自然光]

全身背面展示
[时尚摄影] [纯白背景] 长发女性，佩戴简约耳环。模特全身背面站立，身体微转向左侧，回头看。她穿着黑色方领针织连衣裙，后背的方领剪裁和背部中缝线清晰可见，裙摆自然垂坠。[超高分辨率、清晰细节、自然光]
```

## 视频生成提示词（wan2.6-i2v-flash）

### 图生视频公式（有声版）

**提示词 = 运动（配合语音的动作） + 运镜 + 声音描述**

图像已确定主体、场景和风格，提示词只需描述：
1. **运动描述**：手部动作与语音内容同步
2. **运镜**：镜头运动方式
3. **声音描述**：口语化带货文案 + 情绪 + 语速 + 音色

**关键规则：**
- 手做什么 = 嘴在说什么（动作与语音同步）
- 用"缓慢地""微微""轻柔地"控制幅度
- 文案要口语化，像真实主播在说话
- 不超过 200 字
- **视频基于正面效果图生成**

### 动作与语音同步模板

#### 模板 A：展示面料 + 推进（推荐）
```
镜头缓慢推进，模特面带微笑，右手轻抚{garment_part}展示面料质感，说道："{speech_content}"语气热情亲切，语速轻快。说完后双手在身前自然交叠，微微侧身。
```

#### 模板 B：展示版型 + 固定镜头
```
固定镜头，模特面带微笑，双手在腰线位置轻轻比划展示修身版型，说道："{speech_content}"语气轻松自然，语速适中。说完后右手自然垂放，微微右转展示侧面轮廓。
```

#### 模板 C：展示垂坠感 + 镜头拉远
```
镜头缓慢拉远，模特左手轻提{garment_part}左右轻晃展示垂坠感，说道："{speech_content}"语气温柔亲切，语速适中。说完后双手自然下垂，面带微笑看向镜头。
```

### 口语化带货文案参考（{speech_content}）

由 analyze_image.py 返回的 `selling_points` 字段组合生成。以下为风格参考：

| 产品类型 | 口语化文案示例 |
|---------|--------------|
| 上衣/衬衫 | "姐妹们看这个面料，软糯到不行，上身特别舒服，版型也显瘦，通勤穿它准没错" |
| 连衣裙 | "你们看这个裙摆，走起路来飘逸感拉满，腰线设计特别显身材，约会穿它绝了" |
| 套装 | "这套真的太百搭了，一秒出门不用想搭配，修身版型显瘦又高级" |
| 裤子 | "这条裤子版型绝了，上身显腿长一米八，搭什么都好看，闭眼入" |
| 外套 | "这件外套剪裁超利落，穿上气场全开，秋天必备单品，我已囤了两件" |

**文案原则：**
- 用"姐妹们""你们看""绝了""闭眼入"等口语化表达
- 每句不超过 25 字
- 10 秒视频约 40-50 字（留出动作停顿时间）
- 包含 1-2 个具体卖点 + 1 个使用场景

### 按服装类型的填充词

| 服装类型 | {garment_part} 填充 |
|---------|---------------------|
| 上衣/衬衫/T恤 | 衣袖、衣领、下摆 |
| 连衣裙 | 裙摆、腰线、肩带 |
| 裤子 | 裤脚、腰头、裤腿 |
| 外套/夹克 | 衣领、翻领、拉链 |
| 通用 | 衣服下摆 |

### 反面示例（避免）

```
# 错误1：动作与语音不同步
固定镜头，模特缓慢右转展示侧面，转回正面。模特说道："这件衣服面料特别好。"
# 问题：转身时在说话，但没有配合的手部动作

# 错误2：文案太正式
"这款产品采用优质面料，版型修身显瘦，适合多种场合穿着。"
# 问题：像产品说明书，不像真人说话

# 错误3：描述了图像已确定的内容
"一位模特穿着黑色连衣裙站在摄影棚中，灯光柔和，背景简洁。"
# 问题：图像已确定这些内容，浪费提示词容量
```

## 运镜词典

| 运镜 | 提示词 | 效果 |
|------|--------|------|
| 固定 | 固定镜头 | 镜头不动 |
| 推进 | 镜头缓慢推进 | 镜头向主体靠近 |
| 拉远 | 镜头缓慢拉远 | 镜头远离主体 |
| 左移 | 镜头向左移动 | 镜头水平左移 |
| 右移 | 镜头向右移动 | 镜头水平右移 |
| 上摇 | 镜头上摇 | 镜头从下向上 |
| 下摇 | 镜头下摇 | 镜头从上向下 |
| 环绕 | 环绕运镜 | 镜头绕主体旋转 |
